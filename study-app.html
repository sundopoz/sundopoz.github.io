สัปดาห์ที่ 1

แนวคิดพื้นฐานทางสถิติ นิยามศัพท์ ตัวแปร และระดับมาตรวัดตัวแปร

Basic Statistical Concepts, Definitions, Variables & Measurement Scales

ความหมายของสถิติ

ข้อมูลเชิงสถิติ (Statistical data) — ตัวเลขที่ใช้แทนข้อเท็จจริง เพื่อบรรยายลักษณะของสิ่งที่สนใจ
ระเบียบวิธีทางสถิติ (Statistical methodology) — วิธีการเก็บรวบรวม จัดการ วิเคราะห์ แปลผล และนำเสนอข้อมูล

ประเภทของสถิติ

  • สถิติเชิงพรรณนา (Descriptive statistics) — สรุปสาระสำคัญของข้อมูลชุดหนึ่ง ไม่มีการอ้างอิงไปยังกลุ่มอื่น (ตาราง/แผนภาพ/ตัวเลขสรุป)
  • สถิติเชิงอนุมาน (Inferential statistics) — ใช้ข้อมูลตัวอย่างเพื่อสรุปอ้างอิงถึงประชากร แบ่งเป็น การประมาณค่า (Estimation) และ การทดสอบสมมติฐาน (Hypothesis testing)

นิยามศัพท์สำคัญ

คำศัพท์ความหมาย
ประชากร (Population)สิ่งของทั้งหมดที่สนใจศึกษา
ตัวอย่าง (Sample)ส่วนหนึ่งที่เลือกมาจากประชากร
ตัวแปร (Variable)ลักษณะของสิ่งที่สนใจศึกษาและสังเกต
ค่าสังเกต (Observation)ข้อมูลของตัวแปรที่ได้จากการวัด/สังเกต
พารามิเตอร์ (Parameter)ค่าวัดเชิงตัวเลขที่คำนวณจากประชากร
ค่าสถิติ (Statistic)ค่าวัดเชิงตัวเลขที่คำนวณจากตัวอย่าง

ประเภทของตัวแปร

  • ตัวแปรเชิงคุณภาพ (Qualitative) — บอกกลุ่ม/ประเภท วัดเป็นตัวเลขไม่ได้ (เช่น เพศ สี ยี่ห้อ)
  • ตัวแปรเชิงปริมาณ (Quantitative) — วัดเป็นจำนวน แบ่งเป็น
    • ไม่ต่อเนื่อง (Discrete) — ค่าที่เป็นไปได้เป็นจำนวนเต็ม (เช่น จำนวนคน)
    • ต่อเนื่อง (Continuous) — ค่าที่เป็นไปได้เป็นจำนวนจริง (เช่น น้ำหนัก ส่วนสูง)

ระดับมาตรวัดตัวแปร (4 ระดับ)

มาตราคุณสมบัติตัวอย่าง
1. นามบัญญัติ (Nominal)บอกได้แค่เหมือน/ต่างกันเพศ, สถานภาพสมรส
2. อันดับ (Ordinal)จัดอันดับได้ มาก/น้อยกว่า แต่บอกปริมาณต่างไม่ได้ระดับความพึงพอใจ
3. อันตรภาค (Interval)ระยะห่างเท่ากัน แต่จุดศูนย์ไม่แท้จริงอุณหภูมิ (°C), IQ
4. อัตราส่วน (Ratio)มีจุดศูนย์แท้จริง เปรียบเทียบเป็น "กี่เท่า" ได้น้ำหนัก ส่วนสูง อายุ รายได้
จำง่ายNominal + Ordinal → ตัวแปรเชิงคุณภาพ  |  Interval + Ratio → ตัวแปรเชิงปริมาณ

ที่มาของข้อมูล

  • ข้อมูลปฐมภูมิ (Primary data) — เก็บจากแหล่งกำเนิดโดยตรง: สำมะโน, สำรวจตัวอย่าง, วางแผนทดลอง, ทะเบียน, สังเกตการณ์, สัมภาษณ์, แบบสอบถาม
  • ข้อมูลทุติยภูมิ (Secondary data) — เก็บจากแหล่งที่มีผู้รวบรวมไว้แล้ว (หน่วยงานรัฐ/เอกชน)

การสร้างตารางแจกแจงความถี่ (ขั้นตอน)

ขั้นตอนหลัก \[ R = \max - \min \] \[ \text{ความกว้างของชั้น} = \frac{R}{\text{จำนวนชั้น}} \quad \text{(ปัดขึ้นถ้าไม่ลงตัว)} \] \[ \text{ขีดจำกัดล่างชั้นแรก} = \min, \qquad \text{ขีดจำกัดบน} = \text{ขีดจำกัดล่าง} + \text{ความกว้าง} - 1 \] \[ \text{ขอบเขตบน} = \frac{\text{ขีดจำกัดบน} + \text{ขีดจำกัดล่างชั้นถัดไป}}{2}, \qquad \text{ขอบเขตล่าง} = \text{ขอบเขตบน} - \text{ความกว้าง} \] \[ \text{จุดกึ่งกลางชั้น} = \frac{\text{ขีดจำกัดล่าง} + \text{ขีดจำกัดบน}}{2} \] \[ \text{ความถี่สัมพัทธ์ของชั้น } i = \frac{f_i}{n}, \qquad \text{ความถี่สะสมของชั้น } i = \sum_{j=1}^{i} f_j \]
ตัวอย่าง ข้อมูลอายุ 30 คน, \(\min=22,\ \max=44 \Rightarrow R=22\), ใช้ 6 ชั้น กว้างชั้นละ 4 → ชั้นแรก \([22,25]\), ขอบเขต \(21.5\text{–}25.5\), จุดกึ่งกลาง \(23.5\), ความถี่ \(f_1=5 \Rightarrow\) ความถี่สัมพัทธ์ \(=\dfrac{5}{30}\approx 0.17\)
สรุปสูตร & ตัวแปร — สัปดาห์ 1
พิสัย
\[ R = \max - \min \]
R = พิสัย, max/min = ค่าสูงสุด/ต่ำสุดของข้อมูล
ความกว้างของชั้น
\[ \text{ความกว้าง} = \frac{R}{\text{จำนวนชั้น}} \]
R = พิสัย, จำนวนชั้น = จำนวนชั้นที่ต้องการแบ่ง (ปัดผลลัพธ์ขึ้นเสมอถ้าไม่ลงตัว)
ขีดจำกัด / ขอบเขต / จุดกึ่งกลางชั้น
\[ \text{ขอบเขตบน} = \frac{\text{ขีดจำกัดบน}+\text{ขีดจำกัดล่างชั้นถัดไป}}{2}, \quad \text{จุดกึ่งกลาง} = \frac{\text{ขีดจำกัดล่าง}+\text{ขีดจำกัดบน}}{2} \]
ขีดจำกัดล่างชั้นแรก = min เสมอ; แต่ละชั้นถัดไปบวกความกว้างของชั้นต่อเนื่องกัน
ความถี่สัมพัทธ์ & ความถี่สะสม
\[ \text{ความถี่สัมพัทธ์ชั้น } i = \frac{f_i}{n}, \qquad \text{ความถี่สะสมชั้น } i = \sum_{j=1}^{i} f_j \]
fi = ความถี่ของชั้นที่ i (จำนวนข้อมูลที่ตกในชั้นนั้น), n = จำนวนข้อมูลทั้งหมด

การวัดแนวโน้มสู่ส่วนกลาง

Measures of Central Tendency: Mean, Median, Mode

ค่าเฉลี่ย (Mean)

ค่าเฉลี่ยประชากร / ตัวอย่าง (ไม่ถ่วงน้ำหนัก) \[ \mu = \frac{1}{N}\sum_{i=1}^{N} X_i \qquad\qquad \bar{X} = \frac{1}{n}\sum_{i=1}^{n} X_i \]
ค่าเฉลี่ยถ่วงน้ำหนัก (Weighted mean) \[ \bar{X}_w = \frac{\sum_{i=1}^{k} w_i X_i}{\sum_{i=1}^{k} w_i} \]
ค่าเฉลี่ยสำหรับข้อมูลจัดกลุ่ม (Grouped mean) \[ \bar{X} = \frac{1}{n}\sum_{i=1}^{k} f_i x_i \] \(f_i\) = ความถี่ชั้น \(i\), \(x_i\) = จุดกึ่งกลางชั้น \(i\)
คุณสมบัติของค่าเฉลี่ย \[ 1)\ n\bar{X} = \sum X_i \qquad 2)\ \sum (X_i - \bar{X}) = 0 \] \[ 3)\ \sum (X_i - \bar{X})^2 \text{ มีค่าน้อยที่สุด} \qquad 4)\ Y_i = aX_i+b \Rightarrow \bar{Y} = a\bar{X}+b \]

มัธยฐาน (Median)

ค่าที่แบ่งข้อมูลเรียงลำดับออกเป็น 2 ส่วนเท่ากัน (50%–50%)

ข้อมูลไม่จัดกลุ่ม \[ n \text{ คี่} \Rightarrow \text{มัธยฐาน} = \text{ค่าที่ตำแหน่ง } \frac{n+1}{2} \] \[ n \text{ คู่} \Rightarrow \text{มัธยฐาน} = \text{ค่าเฉลี่ยของตำแหน่ง } \frac{n}{2} \text{ และ } \frac{n}{2}+1 \]
ข้อมูลจัดกลุ่ม \[ \text{มัธยฐาน} = L + I \left( \frac{\frac{n}{2} - F}{f} \right) \] \(L\)=ขอบเขตล่างชั้นมัธยฐาน, \(F\)=ความถี่สะสมก่อนชั้นนั้น, \(f\)=ความถี่ชั้นนั้น, \(I\)=ความกว้างชั้น

ฐานนิยม (Mode)

ค่าที่มีความถี่สูงสุด — อาจมีค่าเดียว หลายค่า หรือไม่มีเลยก็ได้ (Unimodal / Bimodal / Multimodal)

ข้อมูลจัดกลุ่ม \[ \text{ฐานนิยม} = L + I \left( \frac{d_1}{d_1+d_2} \right) \] \(d_1\) = ผลต่างความถี่ชั้นฐานนิยมกับชั้นก่อนหน้า, \(d_2\) = ผลต่างกับชั้นถัดไป

ความสัมพันธ์ระหว่างค่าเฉลี่ย มัธยฐาน ฐานนิยม

\[ \text{ฐานนิยม} = 3(\text{มัธยฐาน}) - 2(\text{ค่าเฉลี่ย}) \]
รูปการแจกแจง เบ้ซ้าย (Negative skew): Mean < Median < Mode  |  สมมาตร: Mean = Median = Mode  |  เบ้ขวา (Positive skew): Mode < Median < Mean
สรุปสูตร & ตัวแปร — สัปดาห์ 2
ค่าเฉลี่ย (ไม่ถ่วงน้ำหนัก)
\[ \mu = \frac{1}{N}\sum X_i \qquad \bar{X} = \frac{1}{n}\sum X_i \]
μ = ค่าเฉลี่ยประชากร, X̄ = ค่าเฉลี่ยตัวอย่าง, Xi = ค่าสังเกตตัวที่ i, N/n = ขนาดประชากร/ตัวอย่าง
ค่าเฉลี่ยถ่วงน้ำหนัก
\[ \bar{X}_w = \frac{\sum w_i X_i}{\sum w_i} \]
wi = น้ำหนักของค่าสังเกตตัวที่ i, Xi = ค่าสังเกตตัวที่ i
ค่าเฉลี่ยข้อมูลจัดกลุ่ม
\[ \bar{X} = \frac{1}{n}\sum f_i x_i \]
fi = ความถี่ชั้น i, xi = จุดกึ่งกลางชั้น i, n = จำนวนข้อมูลทั้งหมด
มัธยฐานข้อมูลจัดกลุ่ม
\[ \text{มัธยฐาน} = L + I\left(\frac{\frac{n}{2}-F}{f}\right) \]
L = ขอบเขตล่างของชั้นที่มีมัธยฐานอยู่, I = ความกว้างของชั้น, F = ความถี่สะสมก่อนถึงชั้นนั้น, f = ความถี่ของชั้นนั้น, n = จำนวนข้อมูลทั้งหมด
ฐานนิยมข้อมูลจัดกลุ่ม
\[ \text{ฐานนิยม} = L + I\left(\frac{d_1}{d_1+d_2}\right) \]
L = ขอบเขตล่างของชั้นฐานนิยม, I = ความกว้างของชั้น, d₁ = (ความถี่ชั้นฐานนิยม − ความถี่ชั้นก่อนหน้า), d₂ = (ความถี่ชั้นฐานนิยม − ความถี่ชั้นถัดไป)
ความสัมพันธ์ 3 ค่ากลาง
\[ \text{ฐานนิยม} = 3(\text{มัธยฐาน}) - 2(\text{ค่าเฉลี่ย}) \]
ใช้ประมาณค่าหนึ่งจากอีกสองค่า เมื่อโจทย์ให้มาไม่ครบ

การวัดตำแหน่งของข้อมูล

Measures of Position: Quartile, Decile, Percentile

เปรียบเทียบตำแหน่งของค่าสังเกตหลังเรียงข้อมูลจากน้อยไปมาก และแบ่งข้อมูลเป็นส่วนเท่าๆ กัน

ชนิดแบ่งเป็นจำนวนค่า
ควอไทล์ (Quartile)4 ส่วนQ₁, Q₂, Q₃
เดไซล์ (Decile)10 ส่วนD₁ … D₉
เปอร์เซ็นไทล์ (Percentile)100 ส่วนP₁ … P₉₉

สูตร (ข้อมูลไม่จัดกลุ่ม — เรียงข้อมูลก่อนเสมอ)

ตำแหน่ง \[ Q_r = \frac{r(n+1)}{4}, \qquad D_r = \frac{r(n+1)}{10}, \qquad P_r = \frac{r(n+1)}{100} \]
ค่าที่ตำแหน่ง (interpolation) \[ V_r = V_a + (r - a)\left(V_{a+1} - V_a\right) \] โดย \(a\) = จำนวนเต็มที่ใกล้ตำแหน่ง \(r\) มากที่สุด และ \(a < r\)

สูตร (ข้อมูลจัดกลุ่ม)

\[ V_r = L + I\left(\frac{\frac{nr}{4}-F}{f}\right) \ \text{(ควอไทล์)}, \qquad V_r = L + I\left(\frac{\frac{nr}{10}-F}{f}\right) \ \text{(เดไซล์)} \] \[ V_r = L + I\left(\frac{\frac{nr}{100}-F}{f}\right) \ \text{(เปอร์เซ็นไทล์)} \] หาชั้นที่มีค่านั้นอยู่ = ชั้นแรกที่ความถี่สะสม \(> \) เกณฑ์ (\(\frac{nr}{4}, \frac{nr}{10}\), หรือ \(\frac{nr}{100}\))

ความสัมพันธ์ที่ต้องจำ

\[ Q_1 = P_{25} \qquad Q_3 = P_{75} \qquad D_1 = P_{10} \qquad D_9 = P_{90} \qquad \text{มัธยฐาน} = Q_2 = D_5 = P_{50} \]

คุณสมบัติเชิงเส้น

ถ้า \(Y = aX + b\) (\(a, b\) เป็นจำนวนจริง) แล้ว:

\[ Q_{y,r} = aQ_{x,r}+b, \qquad D_{y,r} = aD_{x,r}+b, \qquad P_{y,r} = aP_{x,r}+b \]
ตัวอย่าง ข้อมูล 20 ค่า (อายุการใช้งานแบตเตอรี่) เรียงแล้ว: ตำแหน่ง \(Q_1 = \dfrac{1(21)}{4} = 5.25\) → อยู่ระหว่างข้อมูลตำแหน่งที่ 5 และ 6 → ใช้สูตร interpolation ได้ \(Q_1 \approx 2.7\)
สรุปสูตร & ตัวแปร — สัปดาห์ 3
ตำแหน่ง (ข้อมูลไม่จัดกลุ่ม)
\[ Q_r=\frac{r(n+1)}{4}, \quad D_r=\frac{r(n+1)}{10}, \quad P_r=\frac{r(n+1)}{100} \]
r = ลำดับควอไทล์/เดไซล์/เปอร์เซ็นไทล์ที่ต้องการ (เช่น r=1,2,3 สำหรับควอไทล์), n = จำนวนข้อมูล (ต้องเรียงจากน้อยไปมากก่อน)
ค่าที่ตำแหน่ง (interpolation)
\[ V_r = V_a + (r-a)(V_{a+1}-V_a) \]
a = จำนวนเต็มใกล้ตำแหน่ง r มากที่สุดโดยที่ a < r, Va = ค่าข้อมูลที่ตำแหน่ง a, Va+1 = ค่าข้อมูลที่ตำแหน่ง a+1
ข้อมูลจัดกลุ่ม
\[ V_r = L + I\left(\frac{\frac{nr}{4}-F}{f}\right) \]
L = ขอบเขตล่างของชั้นที่มีค่านั้นอยู่, I = ความกว้างชั้น, n = จำนวนข้อมูลทั้งหมด, r = ลำดับที่ต้องการ, F = ความถี่สะสมก่อนชั้นนั้น, f = ความถี่ของชั้นนั้น (สูตรเดียวกัน สลับตัวหาร 4/10/100 ตามชนิด)
↑ กลับสารบัญ
สัปดาห์ที่ 4

การวัดการกระจาย: การกระจายสัมบูรณ์

Absolute Variation: Range, Quartile Deviation, Variance, SD, Mean Deviation

ค่ากลาง (mean/median/mode) บอกได้แค่ตำแหน่งที่ข้อมูลรวมกลุ่ม แต่ไม่บอกว่าข้อมูลกระจายมากน้อยแค่ไหน — จึงต้องใช้ค่าวัดการกระจายเสริม

1. พิสัย (Range) & พิสัยระหว่างควอไทล์ (IQR)

\[ \text{พิสัย} = \max - \min \qquad \text{IQR} = Q_3 - Q_1 \] ตารางแจกแจงความถี่ \[ \text{พิสัย} = \text{ขอบเขตบนชั้นสูงสุด} - \text{ขอบเขตล่างชั้นต่ำสุด} \]

2. ส่วนเบี่ยงเบนควอไทล์ (Quartile Deviation)

\[ QD = \frac{Q_3 - Q_1}{2} \]

3. ความแปรปรวน (Variance) & ส่วนเบี่ยงเบนมาตรฐาน (SD)

ประชากร \[ \sigma^2 = \frac{1}{N}\sum_{i=1}^{N} (X_i - \mu)^2 \]
ตัวอย่าง (หาร n−1) \[ S^2 = \frac{1}{n-1}\sum_{i=1}^{n} (X_i - \bar{X})^2 \]
ข้อมูลจัดกลุ่ม \[ S^2 = \frac{1}{n-1}\sum_{i=1}^{k} f_i (X_i - \bar{X})^2 \]
\[ S = \sqrt{\text{ความแปรปรวน}} \]
ระวังประชากรหารด้วย \(N\), ตัวอย่างหารด้วย \(n-1\) (ไม่ใช่ \(n\)) — จุดที่ออกข้อสอบบ่อย! ความแปรปรวนของค่าคงที่ = 0

4. ส่วนเบี่ยงเบนเฉลี่ย (Mean Deviation)

\[ \text{ประชากร: } \frac{1}{N}\sum |X_i - \mu| \qquad \text{ตัวอย่าง: } \frac{1}{n}\sum |X_i - \bar{X}| \qquad \text{จัดกลุ่ม: } \frac{1}{n}\sum f_i |X_i - \bar{X}| \]

คุณสมบัติเชิงเส้น (ถ้า \(Y_i = aX_i + b\))

\[ QD_y = |a|\,QD_x, \qquad S_y^2 = a^2 S_x^2, \qquad S_y = |a|\,S_x \]
จำง่ายบวกค่าคงที่ \(b\) ไม่กระทบการกระจายเลย มีแต่ตัวคูณ \(a\) เท่านั้นที่กระทบ (และ SD/QD ใช้ค่าสัมบูรณ์ของ \(a\) เสมอ)
ตัวอย่าง ความเร็วรถ 13 คัน → \(\bar{X} \approx 118.77\) → \(S^2 = \dfrac{\sum(X_i-\bar{X})^2}{13-1} \approx 61.86\) → \(S = \sqrt{61.86} \approx 7.87\) km/h
สรุปสูตร & ตัวแปร — สัปดาห์ 4
พิสัย & IQR
\[ \text{พิสัย}=\max-\min, \qquad IQR = Q_3-Q_1 \]
Q₁, Q₃ = ควอไทล์ที่ 1 และ 3 ของข้อมูล
ส่วนเบี่ยงเบนควอไทล์
\[ QD = \frac{Q_3-Q_1}{2} \]
Q₁, Q₃ = ควอไทล์ที่ 1 และ 3
ความแปรปรวน (ประชากร/ตัวอย่าง/จัดกลุ่ม)
\[ \sigma^2=\frac{1}{N}\sum(X_i-\mu)^2, \quad S^2=\frac{1}{n-1}\sum(X_i-\bar{X})^2, \quad S^2=\frac{1}{n-1}\sum f_i(X_i-\bar{X})^2 \]
σ² = ความแปรปรวนประชากร (หารด้วย N), S² = ความแปรปรวนตัวอย่าง (หารด้วย n−1 เสมอ ไม่ใช่ n), μ/X̄ = ค่าเฉลี่ยประชากร/ตัวอย่าง, fi, Xi = ความถี่และจุดกึ่งกลางชั้น i (กรณีจัดกลุ่ม)
ส่วนเบี่ยงเบนมาตรฐาน
\[ S=\sqrt{S^2} \quad \text{หรือ} \quad \sigma=\sqrt{\sigma^2} \]
รากที่สองของความแปรปรวน — มีหน่วยเดียวกับข้อมูลต้นฉบับ
ส่วนเบี่ยงเบนเฉลี่ย
\[ \frac{1}{N}\sum|X_i-\mu| \quad \text{หรือ} \quad \frac{1}{n}\sum|X_i-\bar{X}| \quad \text{หรือ} \quad \frac{1}{n}\sum f_i|X_i-\bar{X}| \]
ใช้ n (ไม่ใช่ n−1) เป็นตัวหารเสมอ ต่างจากความแปรปรวน/SD
คุณสมบัติเชิงเส้น (Y = aX + b)

การวัดการกระจาย: การกระจายสัมพัทธ์

Relative Variation — ใช้เปรียบเทียบการกระจายระหว่างข้อมูลต่างชุด/ต่างหน่วย

1. สัมประสิทธิ์พิสัย (Coefficient of Range, C.R.)

\[ C.R. = \frac{\max - \min}{\max + \min} \times 100 \]

2. สัมประสิทธิ์ส่วนเบี่ยงเบนควอไทล์ (C.Q.D.)

\[ C.Q.D. = \frac{Q_3 - Q_1}{Q_3 + Q_1} \times 100 \]

3. สัมประสิทธิ์ส่วนเบี่ยงเบนเฉลี่ย (C.M.D.)

\[ C.M.D. = \frac{\text{ส่วนเบี่ยงเบนเฉลี่ย}}{\bar{X}} \times 100 \]

4. สัมประสิทธิ์ความผันแปร (Coefficient of Variation, C.V.)

\[ \text{ประชากร: } C.V. = \frac{\sigma}{\mu}\times 100 \qquad \text{ตัวอย่าง: } C.V. = \frac{S}{\bar{X}}\times 100 \]
ใช้เมื่อไรC.V. เป็นค่าที่ไม่มีหน่วย เหมาะสำหรับเปรียบเทียบการกระจายของข้อมูลคนละหน่วยหรือคนละขนาด (เช่น เปรียบเทียบความผันแปรของน้ำหนักกับส่วนสูง) — ค่า C.V. มาก = กระจายมากกว่า
ตัวอย่าง หลอดไฟ A: อายุเฉลี่ย 1495 ชม., \(S=590\) → \(CV_A \approx 39.5\%\)
หลอดไฟ B: อายุเฉลี่ย 1255 ชม., \(S=245\) → \(CV_B \approx 19.5\%\)
→ B มีคุณภาพการผลิตสม่ำเสมอกว่า (CV ต่ำกว่า) แม้ A จะมีอายุการใช้งานเฉลี่ยนานกว่า
สรุปสูตร & ตัวแปร — สัปดาห์ 5

\[ C.M.D. = \frac{\text{ส่วนเบี่ยงเบนเฉลี่ย}}{\bar{X}}\times 100 \]

σ/S = ส่วนเบี่ยงเบนมาตรฐานของประชากร/ตัวอย่าง, μ/X̄ = ค่าเฉลี่ยของประชากร/ตัวอย่าง — ค่านี้ไม่มีหน่วย ใช้เทียบข้อมูลต่างหน่วยกันได้

แนวคิดและกระบวนการทดสอบสมมติฐานทางสถิติ

Hypothesis Testing — Concepts & Procedure

สมมติฐานทางสถิติ (Statistical Hypothesis)

ข้อความเกี่ยวกับประชากรที่อาจจะจริงหรือไม่จริง — เนื่องจากตรวจสอบทุกหน่วยของประชากรทำไม่ได้จริง จึงทดสอบจากตัวอย่างแทน

สมมติฐานว่าง (Null hypothesis, \(H_0\)) — ข้อความที่กำหนดให้เป็นจริงขณะทดสอบ (มักเขียนด้วย \(=, \leq, \geq\))
สมมติฐานแย้ง (Alternative hypothesis, \(H_1\) หรือ \(H_a\)) — ข้อความที่ตรงข้ามกับ \(H_0\) เป็นสิ่งที่ต้องการพิสูจน์ว่าจริง (มักเขียนด้วย \(\neq, <, >\))

องค์ประกอบของการทดสอบ

  • ตัวสถิติทดสอบ (Test statistic) — ฟังก์ชันของตัวอย่างสุ่มที่ใช้ตัดสินใจ (เช่น \(\bar{X}\))
  • บริเวณวิกฤต (Critical region, \(C\)) — ถ้าค่าตัวสถิติทดสอบตกอยู่ในนี้ → ปฏิเสธ \(H_0\)
  • บริเวณยอมรับ (Acceptance region, \(C'\)) — ถ้าตกอยู่ในนี้ → ยอมรับ \(H_0\)

ความคลาดเคลื่อน (Error)

ชนิดนิยามสัญลักษณ์
Type I errorปฏิเสธ \(H_0\) ทั้งที่ \(H_0\) เป็นจริง\(\alpha\) (ระดับนัยสำคัญ)
Type II errorยอมรับ \(H_0\) ทั้งที่ \(H_0\) ไม่จริง\(\beta\)
จำง่าย\(\alpha\) เกี่ยวกับการ "ปฏิเสธของจริง" (false alarm), \(\beta\) เกี่ยวกับการ "ยอมรับของปลอม" (missed detection)

ขั้นตอนการทดสอบสมมติฐาน (5 ขั้นตอน)

1. ตั้งสมมติฐาน \(H_0\) (\(=, \leq,\) หรือ \(\geq\)) และ \(H_1\) (\(\neq, <,\) หรือ \(>\))
2. กำหนดระดับนัยสำคัญ \(\alpha\)
3. เลือกตัวสถิติทดสอบ และกำหนดบริเวณวิกฤต
4. คำนวณค่าตัวสถิติทดสอบจากตัวอย่างขนาด \(n\)
5. สรุปผล: ค่าอยู่ในบริเวณวิกฤต → ปฏิเสธ \(H_0\) / ไม่อยู่ → ยอมรับ \(H_0\)
ตัวอย่าง บริษัทสงสัยว่าหลอดไฟมีอายุการใช้งานมากกว่า 1500 ชม. หรือไม่
\[ H_0: \mu \leq 1500 \quad \text{vs} \quad H_1: \mu > 1500, \qquad \alpha = 0.05 \] ตัวสถิติทดสอบ \(= \bar{X}\), บริเวณวิกฤต \(C = \{\bar{X} > 1647\}\)
สุ่มตัวอย่างได้ \(\bar{X} = 1497\) ซึ่ง \(1497 \leq 1647\) → ไม่อยู่ในบริเวณวิกฤต → ยอมรับ \(H_0\) (สรุปว่าอายุการใช้งานไม่ได้มากกว่า 1500 ชม. ที่ \(\alpha=0.05\))
สรุปสัญลักษณ์ & แนวคิด — สัปดาห์ 8
รูปแบบสมมติฐาน
\[ H_0: \mu \leq \mu_0 \ \text{หรือ}\ \mu \geq \mu_0 \ \text{หรือ}\ \mu = \mu_0 \qquad H_1: \mu > \mu_0 \ \text{หรือ}\ \mu < \mu_0 \ \text{หรือ}\ \mu \neq \mu_0 \]
H₀ = สมมติฐานว่าง (สิ่งที่ตั้งให้เป็นจริงไว้ก่อน), H₁ (Ha) = สมมติฐานแย้ง (สิ่งที่ต้องการพิสูจน์), μ₀ = ค่าพารามิเตอร์ที่ระบุในโจทย์ (ค่าอ้างอิง)
บริเวณวิกฤต (ตัวอย่างรูปแบบ)
\[ C = \{\bar{X} > c\} \quad \text{หรือ} \quad \{\bar{X} < c\} \quad \text{หรือ} \quad \{|\bar{X}-\mu_0| > c\} \]
C = บริเวณวิกฤต (เซตของค่าที่ทำให้ปฏิเสธ H₀), c = ค่าคงที่ที่โจทย์กำหนด/คำนวณจาก α, X̄ = ตัวสถิติทดสอบ (ค่าเฉลี่ยตัวอย่าง)
ความคลาดเคลื่อน
\[ \alpha = P(\text{ปฏิเสธ } H_0 \mid H_0 \text{ จริง}) \qquad \beta = P(\text{ยอมรับ } H_0 \mid H_0 \text{ ไม่จริง}) \]
α = ระดับนัยสำคัญ / Type I error, β = Type II error — ทั้งคู่เป็นความน่าจะเป็นของการตัดสินใจผิดพลาด
