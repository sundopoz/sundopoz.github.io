01 · Mechanics

Kinematics
จลนศาสตร์

ศึกษาการเคลื่อนที่โดยไม่สนใจสาเหตุ · position, velocity, acceleration และ time คือตัวแปรหลัก

Decision Workflow

1

ระบุตัวแปรที่รู้ vs ไม่รู้

จดตาราง: รู้ s? u? v? a? t? ต้องการหาอะไร? ถ้ามีตัวที่รู้ 3 ตัวจาก 5 → เลือก SUVAT ที่ไม่มีตัวไม่รู้นั้นอยู่

a คงที่

ใช้ SUVAT equations ตรงๆ ไม่ต้อง integrate

a = f(t)

v = ∫a dt · x = ∫v dt

a = f(x)

ใช้ a = v(dv/dx) เพื่อหา v–x relation

2

มีกี่วัตถุ / กี่มิติ?

2D ต้องแยก x และ y components เสมอ ทั้งสองทิศเป็นอิสระต่อกัน

Projectile

x: vₓ = v₀cosθ คงที่ · y: aᵧ = −g · แยกคำนวณ

หลายวัตถุ

หา relative kinematics: xₐ − x_b · เงื่อนไข collision = xₐ = x_b

3

มี path constraint ไหม?

ถ้าเคลื่อนที่บน curve y = f(x) ให้ differentiate path เพื่อหา vᵧ/vₓ และ aᵧ/aₓ

เช่น วงกลม

centripetal a = v²/r · เพิ่ม tangential a ถ้า speed เปลี่ยน

Key Equations

SUVAT (a คงที่)

v = u + at

v = u + at

ไม่มี s

s = ut + ½at²

s = ut + ½at²

ไม่มี v

v² = u² + 2as

v² = u² + 2as

ไม่มี t

s = ½(u+v)t

s = ½(u+v)t

ไม่มี a

Projectile range

R = v₀²sin(2θ)/g

θ = 45° → max range

Centripetal

a_c = v²/r = ω²r

Common Pitfalls

⚠️

Projectile: vₓ ≠ 0 ตลอดทาง

แนวนอนไม่มีแรง → vₓ คงที่ตลอด · aₓ = 0 เสมอ ไม่มี cos(θ) ในแนวนอนหลังออกจากมือ

⚠️

เลือก SUVAT ผิดตัว

จดตาราง known/unknown ก่อนเสมอ แล้วเลือก equation ที่มีตัวไม่รู้แค่ 1 ตัว

Dimension

ทุก term ต้องมีหน่วยเดียวกัน

t ≥ 0

เวลาต้องไม่ติดลบ

Limit

θ=0, θ=90°: ผลสมเหตุสมผลไหม?

Sign

กำหนด +/− ทิศทางแล้วยึดตลอด

02 · Mechanics

Dynamics
พลศาสตร์ · Newton's Laws

FBD ทุกวัตถุแยกกัน ห้ามข้าม · เขียน ΣF = ma ทุกทิศ · ระบุ friction regime ก่อนใช้ค่า μ

Decision Workflow

1

วาด Free Body Diagram ทุกวัตถุแยกกัน

ห้ามรวมวัตถุ · วาดแรงทุกแรงที่กระทำต่อวัตถุนั้นเท่านั้น ไม่วาดแรงที่วัตถุนั้นกระทำต่อผู้อื่น

ห้ามลืม

Normal force N · tension T · friction f · weight mg · constraint force

2

เลือก coordinate system ที่ชาญฉลาด

แกนขนานกับ acceleration เสมอ · บนพื้นเอียง: แกน x ขนานกับพื้นเอียง → ลด component

เขียน ΣF = ma

ทุก component แยกกัน: ΣFₓ = maₓ · ΣFᵧ = maᵧ

3

ระบุ Friction Regime

ต้องถามก่อนว่า static หรือ kinetic? → ใช้ค่า μ ที่ถูกต้อง

Assume static ก่อน

หา f ที่ต้องการ · ถ้า f ≤ μ_s N → static OK

ถ้า f > μ_s N

slip! → ใช้ f = μ_k N แทน · เปลี่ยน equation

4

Constraint equations

วัตถุที่ต่อกัน: ความสัมพันธ์ระหว่าง a ของแต่ละวัตถุ · Atwood: a₁ = −a₂ · Pulley: ลด string length

นับ eq vs unknown

ต้องมี equations = unknowns · N equations จาก N วัตถุ + constraint

Key Equations

Newton's Laws

Newton 2nd

ΣF = ma

Normal force (on slope)

N = mg cosθ + ma_⊥

ถ้า a มี component ตั้งฉากกับผิว

Friction

f_s ≤ μ_s N · f_k = μ_k N

Circular motion

ΣF_radial = mv²/r

Drag (low speed)

f_drag = bv

terminal: mg = bv_t

Common Pitfalls

⚠️

N ≠ mg เสมอ

ถ้าวัตถุ accelerating หรืออยู่บนโค้ง N จะ ≠ mg ต้องเขียน FBD และ Newton 2nd ก่อนแทนค่า

⚠️

Reaction force ≠ แรงที่ act บนวัตถุเดิม

Newton 3rd: แรงคู่ action-reaction act บนวัตถุคนละตัว ห้ามใส่ทั้งคู่ใน FBD เดียวกัน

Sanity Checks

N ≥ 0

ถ้า N < 0 → วัตถุลอยแล้ว เปลี่ยน model

a = 0 limit

ถ้า a = 0 ต้องได้ static equilibrium

Direction

แรงสุทธิชี้ทิศเดียวกับ a

03 · Mechanics

Energy
พลังงาน · งาน · กำลัง

จำแนก conservative vs non-conservative ก่อน · เลือก Newton หรือ Work-Energy ตาม type ของปัญหา

Decision Workflow

1

จำแนกแรงในระบบ

แยก conservative (gravity, spring, electric) กับ non-conservative (friction, air resistance) เพราะสมการที่ใช้ต่างกัน

Conservative only

ΔKE + ΔPE = 0 · conservation of mechanical energy

มี non-conservative

W_nc = ΔKE + ΔPE · W_nc = energy lost to friction, etc.

2

เลือก Newton vs Work-Energy

Newton ดีเมื่อต้องการรู้ a และ force ทุก instant · Work-Energy ดีเมื่อถามถึง velocity ที่ final state โดยไม่ต้องรู้ระหว่างทาง

Work-Energy theorem

W_total = ΔKE = ½mv_f² − ½mv_i² · ใช้เมื่อ path ซับซ้อนแต่รู้ initial/final state

3

เลือก reference point ของ PE

PE เปลี่ยนตาม reference ที่เลือก แต่ ΔPE ไม่เปลี่ยน · เลือก reference ที่ทำให้คำนวณง่ายที่สุด

Gravity

PE = mgh · h วัดจาก reference point ที่เลือก (ไม่จำเป็นต้องเป็นพื้น)

Spring

PE = ½kx² · x จาก natural length ไม่ใช่จากพื้น!

Key Equations

Work, Energy & Power

Work

W = F·d·cosθ = F⃗·d⃗

Work-Energy theorem

W_net = ΔKE = ½mv_f² − ½mv_i²

Conservation of energy

KE_i + PE_i = KE_f + PE_f

conservative forces only

Spring PE

PE_spring = ½kx²

x จาก natural length

Power

P = dW/dt = F⃗·v⃗

Non-conservative work

W_nc = ΔKE + ΔPE = ΔE_total

Common Pitfalls

⚠️

Spring PE: x จาก natural length ไม่ใช่จากพื้น

ใน Atwood with spring ให้วาด diagram ระบุ natural length ก่อน แล้วหา x = extension จาก natural length เท่านั้น

⚠️

W ของ normal force = 0

N ⊥ displacement เสมอ → W_N = 0 · ไม่มีผลต่อ energy balance

Sanity Checks

KE ≥ 0

kinetic energy เป็นลบไม่ได้

Energy conserved

ถ้าไม่มี friction: KE+PE คงที่

W_friction < 0

friction ลด mechanical energy เสมอ

04 · Mechanics

Momentum & Collisions
โมเมนตัมและการชน

เช็ก F_ext = 0 ก่อน · จำแนก elastic/inelastic · CoM frame ทำ elastic collision ง่ายขึ้นมาก

Decision Workflow

1

F_ext = 0 ไหม? (ใช้ momentum conservation)

collision ช่วงสั้นๆ → แรงภายนอกเล็กมากเทียบกับ impulsive force → momentum conserved ได้

F_ext ≈ 0

p_total conserved · Σp_i = Σp_f · ใช้ทุก direction

F_ext ≠ 0

ใช้ impulse: Δp = ∫F dt = FΔt (average)

2

จำแนก collision type

Elastic

KE conserved ด้วย · 2 equations: p และ KE

Perfectly inelastic

ติดกัน v_f เดียว · ใช้ p อย่างเดียว

Partial inelastic

ต้องมีข้อมูลเพิ่ม: coefficient of restitution e = v_rel_f/v_rel_i

3

CoM Frame — shortcut สำหรับ elastic collision

ใน CoM frame: p_total = 0 ดังนั้น หลัง elastic collision ทุกวัตถุแค่กลับทิศ velocity แล้ว transform กลับ lab frame

v_cm

v_cm = Σ(m_i·v_i)/Σm_i · v'_i = v_i − v_cm

Key Equations

Momentum & Collisions

Momentum

p⃗ = mv⃗ · ΣF = dp/dt

Impulse

J⃗ = Δp⃗ = ∫F⃗ dt = F_avg·Δt

Conservation

Σp⃗_i = Σp⃗_f

Elastic 1D (สูตรสำเร็จ)

v₁' = (m₁−m₂)v₁/(m₁+m₂) + 2m₂v₂/(m₁+m₂)

Coeff. of restitution

e = |v_rel_f|/|v_rel_i|

e=1: elastic · e=0: perfectly inelastic

Center of mass

x_cm = Σm_i·x_i/Σm_i

Common Pitfalls

⚠️

Momentum เป็น vector

conservation ใช้ทุก component แยกกัน · ใน 2D ต้องมี 2 equations (x, y) · อย่า conserve magnitude เฉยๆ

⚠️

Elastic ≠ ไม่มีแรงกระทำ

Elastic หมายความว่า KE conserved ไม่ใช่ว่าไม่มีแรง · perfectly elastic collision มีแรงมากมายระหว่างชน

Sanity Checks

p_total conserved

ตรวจทุก component

KE_f ≤ KE_i

KE ลดหรือคงที่ ไม่มีทาง> KE_i

e ∈ [0,1]

coefficient of restitution

05 · Mechanics

Rotational Mechanics
กลศาสตร์การหมุน

ทุกอย่างใน translation มี rotation analog · mapping: m↔I, F↔τ, p↔L · เลือก axis ที่ทำให้ τ จากแรงไม่รู้ = 0

Decision Workflow

1

หา Moment of Inertia I

จำ I ของ shapes พื้นฐาน · ใช้ Parallel Axis Theorem เมื่อ axis ไม่ผ่าน CoM

Solid sphere

I = (2/5)MR²

Disk / solid cyl.

I = (1/2)MR²

Hollow sphere

I = (2/3)MR²

Rod (center)

I = (1/12)ML² · end: (1/3)ML²

Parallel Axis

I = I_cm + Md²

2

เลือก axis สำหรับ torque equation

เลือก pivot ที่ทำให้ torque จากแรงไม่รู้ = 0 ลด unknowns ได้ทันที

τ = Iα

ΣF = ma และ Στ = Iα ต้องเขียนพร้อมกัน

Torque

τ = r×F = rF sinθ = r_⊥F = rF_⊥ · เลือกรูปแบบที่ง่ายที่สุด

3

Rolling without slipping

Constraint: v_cm = ωR · a_cm = αR · มักเขียน 2 equations พร้อมกัน (translational + rotational)

ตรวจ constraint

ถ้า μ ≥ threshold → rolling · ถ้า < threshold → slipping → ใช้ f = μ_k N

4

Angular Momentum Conservation

ใช้เมื่อ Στ_ext = 0 · ระวัง L เป็น vector ทิศด้วยก็ conserved

L = Iω

I₁ω₁ = I₂ω₂ · spinning ice skater, collapsing star

Key Equations

Rotational Dynamics & Energy

Newton 2nd (rotation)

Στ = Iα

Angular momentum

L = Iω · τ = dL/dt

Rolling KE

KE = ½mv² + ½Iω² = ½mv²(1 + I/mr²)

Parallel Axis

I = I_cm + Md²

Rolling constraint

v_cm = ωR · a_cm = αR

Common Pitfalls

⚠️

ลืม I_cm ใช้ Parallel Axis ผิด

Parallel Axis ใช้ I_cm ก่อนเสมอ ไม่ใช่ I ของ axis อื่น · I = I_cm + Md² ต้อง d คือระยะจาก cm

⚠️

เลือก axis ผิดทำให้ τ ซับซ้อน

เลือก pivot ที่ทำให้ unknown forces ผ่าน → τ = 0 จะได้สมการที่ไม่มี unknown นั้น

Sanity Checks

v = ωR

rolling: ตรวจ constraint

I ≥ 0

moment of inertia เป็น positive

Units

τ [N·m] · L [kg·m²/s]

06 · Mechanics

Simple Harmonic Motion
การสั่นแบบฮาร์มอนิกอย่างง่าย

สัญญาณ SHM: F = −kx รูปแบบนี้อาจซ่อนอยู่ · หา equilibrium ก่อน แล้ว expand รอบนั้น

Decision Workflow

1

หา equilibrium position

Set F_net = 0 หรือ V'(x) = 0 · equilibrium คือจุดที่ระบบ "ต้องการ" อยู่

2

Set ξ = x − x_eq และ Taylor expand

เก็บแค่ first-order term · ถ้าได้ ξ̈ = −ω²ξ → SHM confirmed · ω² = coefficient

ได้ F = −kξ

SHM · ω = √(k/m) · T = 2π√(m/k)

ไม่ได้รูปแบบ F = −kξ

ไม่ใช่ SHM · ต้องใช้วิธีอื่น

3

หา ω, A, φ จาก Initial Conditions

x(t) = A cos(ωt + φ) · x(0) = x₀ · v(0) = v₀ · A = √(x₀² + v₀²/ω²)

Energy approach

E = ½kA² = ½mv² + ½kx² · หา A จาก energy conservation

4

Damping regime (ถ้ามี)

Underdamped b² < 4mk

oscillates · ω_d = √(ω₀² − γ²) · amplitude ลดลง

Critically damped b² = 4mk

return to eq เร็วที่สุดโดยไม่ oscillate

Overdamped b² > 4mk

return ช้า ไม่ oscillate

Key Equations

SHM Core

General solution

x(t) = A cos(ωt + φ)

Angular frequency

ω = √(k/m) · T = 2π/ω = 2π√(m/k)

Pendulum (small θ)

ω = √(g/L) · T = 2π√(L/g)

Energy

E = ½kA² = ½mv² + ½kx²

Max velocity

v_max = Aω (at x = 0)

Max acceleration

a_max = Aω² (at x = ±A)

Common Pitfalls

⚠️

Pendulum: θ ต้องน้อย (< ~15°) สำหรับ SHM

sin θ ≈ θ ใช้ได้เมื่อ θ ในหน่วย radian และมีค่าน้อย · θ ใหญ่ต้องใช้ elliptic integral หรือ numerical

⚠️

A ≠ x_initial เสมอ

A ขึ้นกับทั้ง x₀ และ v₀ · A = √(x₀² + (v₀/ω)²) · ถ้าปล่อยจากหยุด: A = x₀

Sanity Checks

ω² > 0

ถ้า ω² < 0 → ไม่ใช่ stable equilibrium

E คงที่

no damping: E = ½kA² = constant

T ∝ √(m/k)

มวลมาก → oscillate ช้า

07 · Mechanics

Gravitation
ความโน้มถ่วง · วงโคจร

Shell theorem + Gauss → ลด complexity · orbital mechanics ใช้ energy + angular momentum conservation

Decision Workflow

1

มี Symmetry → Gauss's Law for Gravity

∮ g⃗·dA⃗ = −4πGM_enc · เลือก Gaussian surface ทรงกลม

r > R (outside)

g = GM/r² · เหมือนมวลรวมอยู่ที่ center

r < R (inside uniform)

g = GMr/R³ · เพิ่มขึ้นเชิงเส้นจาก center

Shell theorem

Spherical shell → g = 0 ภายใน shell อย่างสมบูรณ์

2

Orbital Mechanics

ใช้ conservation of energy และ angular momentum พร้อมกัน

Circular orbit

mv²/r = GMm/r² → v = √(GM/r) · T² ∝ r³ (Kepler 3rd)

Elliptical orbit

E = −GMm/2a · a = semi-major axis · L conserved ตลอด orbit

Escape velocity

E_total = 0 → v_esc = √(2GM/r)

Key Equations

Gravity & Orbits

Newton's Gravity

F = GMm/r²

Gravitational PE

U = −GMm/r

Orbital velocity

v = √(GM/r)

Kepler 3rd Law

T² = (4π²/GM)r³

Escape velocity

v_esc = √(2GM/r)

Total orbital energy

E = −GMm/(2a)

a = semi-major axis

Common Pitfalls

⚠️

PE = −GMm/r (ติดลบ)

reference PE = 0 ที่ r = ∞ ดังนั้น PE < 0 เสมอ · bound orbit มี E = KE + PE < 0

Sanity Checks

E < 0

bound orbit: total energy ติดลบ

T² ∝ r³

Kepler 3rd: ตรวจ orbital period

v_esc = √2 · v_orbit

สำหรับ circular orbit

08 · Fluids

Fluid Mechanics
กลศาสตร์ของไหล

Static หรือ Dynamic? Ideal หรือ Viscous? คำตอบกำหนด equations ทั้งหมด · Bernoulli ใช้ได้ along streamline เท่านั้น

Decision Workflow

1

ระบุ Flow Regime

Fluid static

ใช้ P = P₀ + ρgh · buoyancy = ρ_fluid·V_sub·g

Fluid dynamic, ideal

Bernoulli + Continuity · P + ½ρv² + ρgh = const

Viscous

Poiseuille flow: Q = πr⁴ΔP/(8ηL)

2

Bernoulli — ระวัง conditions

ใช้ได้เฉพาะ: ideal fluid (incompressible, inviscid) · along a streamline · steady flow

ใช้คู่กับ Continuity

A₁v₁ = A₂v₂ · ลด unknowns ก่อน Bernoulli

3

Force บน fluid/container

ใช้ momentum theorem: F = ṁ(v_out − v_in) · ṁ = ρAv

Key Equations

Fluid Statics & Dynamics

Pressure in fluid

P = P₀ + ρgh

Archimedes (buoyancy)

F_b = ρ_fluid·V_sub·g

Continuity

A₁v₁ = A₂v₂ = Q = const

Bernoulli

P + ½ρv² + ρgh = const

Torricelli

v = √(2gh)

ไหลจากรูที่ depth h

Surface tension

ΔP = 2γ/r (drop) · 4γ/r (bubble)

Common Pitfalls

⚠️

Bernoulli ใช้ได้เฉพาะ ideal + along streamline

ห้ามใช้ข้าม streamlines · ถ้า fluid มี viscosity หรือ turbulent ไม่ได้ใช้ Bernoulli

Sanity Checks

v เพิ่ม → P ลด

Bernoulli: constriction → faster → lower P

Av = const

continuity ทุก cross-section

F_b = ρVg

ขึ้นกับ fluid density ไม่ใช่ object density

09 · Thermodynamics

Thermodynamics
อุณหพลศาสตร์

วาด PV diagram ก่อนเสมอ · area ใต้เส้น = W · ΔU = nCᵥΔT เสมอ ไม่ว่า process จะเป็นอะไร

Decision Workflow

1

วาด PV diagram และระบุ process

Isothermal T คงที่

PV = const · เส้น hyperbola · W = nRT ln(V_f/V_i)

Isobaric P คงที่

เส้นตรงแนวนอน · W = PΔV

Isochoric V คงที่

เส้นตรงแนวตั้ง · W = 0

Adiabatic Q = 0

PVᵞ = const · ชันกว่า isothermal เสมอ
